
# 🦁 Know Your Fan - FURIA Challenge

Este projeto é uma solução desenvolvida para o desafio **"Know Your Fan"** da FURIA. O objetivo é conhecer melhor os fãs de e-sports por meio de um perfil interativo, com coleta de dados, simulação de validação com IA e análise de comportamento.

## 🎯 Objetivo

Construir um aplicativo que colete o máximo de informações sobre o fã, simulando funcionalidades de IA e integração com redes sociais, possibilitando oferecer experiências personalizadas.

---

## 🛠 Funcionalidades

- ✅ Cadastro de dados pessoais (nome, idade, e-mail, gênero, time/jogador favorito, etc.)
- ✅ Seleção de gêneros de jogos favoritos
- ✅ Upload simulado de documentos
- ✅ Simulação de validação do documento (IA fake)
- ✅ Vinculação simulada de redes sociais
- ✅ Compartilhamento de links de perfis relacionados a e-sports
- ✅ Análise de progresso com barra de status
- ✅ Classificação do fã (Novato, Casual, Super Fã)

## 🧪 Como rodar localmente

1. Clone este repositório:
```bash
git clone https://github.com/RobertoSantos98/know-your-fan.git
```

2. Instale as dependências:
```bash
npm install
```

3. Inicie o servidor local:
```bash
npm run dev
```

## 🤖 Simulações de IA
